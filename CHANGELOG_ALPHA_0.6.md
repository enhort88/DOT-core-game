# DOT//CORE Alpha 0.6

- Drone combat radius reduced to 620 and gun/missile drones now close with targets.
- Kamikaze drones now physically chase a target and detonate only on contact.
- First kamikaze purchase unlocks the type; later kamikaze spawns are much cheaper.
- Drone cap raised from 9/11 to 11/13 (base / +2 late skill).
- Drone aura element is configured independently from drone weapon element.
- Fire/Ice/Lightning purchases moved to a dedicated Effect Shop.
- Gravity pull is resisted by tank/elite enemies and strongly resisted by bosses unless the gravity effect is highly charged.
- Enemy attacks are visible projectile shots instead of unexplained red beams.
- Save slots show wave and credits and now have a delete button.
- Enemy Speed icon is loaded correctly.
- UI text was enlarged across menus, shops and combat HUD.
- Turret weapon and turret element remain in Effect Setup.
