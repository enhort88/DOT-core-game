# DOT//CORE Alpha 0.9 — Balance / UX / Music

- Removed the General shop tab and disabled legacy general combat multipliers.
- Passive income no longer advances inside any shop/configuration/pause overlay.
- Debuffs rebalanced: lower prices and much stronger passive-income bonuses.
- Debuff screen reorganized into Enemy Power / Pressure / Economy sections.
- Effect Setup reorganized into Finger / Turrets / Drones groups.
- Added short pulse animation when opening Shop, Debuffs, Effect Setup / Effect Shop.
- Wave 1 converted to an introductory wave with slow normal enemies and no enemy fire.
- From wave 2 enemy variety and hostile fire are enabled; spawn pressure increases by wave.
- Enemy speed now rises slightly each wave and more after bosses.
- Slightly reduced the default fire rate of pulse turrets, laser and rockets.
- Added original looping ambient space music.
- Added music volume setting (0/25/50/75/100%).
- Updated version to 0.9.0-alpha.
