# DOT//CORE Alpha 0.7 — Space UI / Enemy Debuffs

- Enemy difficulty upgrades moved out of the main shop into a dedicated **Debuffs** screen.
- Debuffs are cheaper and now include enemy density, spawn rate, reward/value, movement speed, damage and health.
- Every debuff increases passive income; test mode still keeps purchases free.
- Fresh saves start with **0 turrets**. Every turret must be bought.
- Enemy health and damage now have independent scaling.
- Enemies prioritize nearby drones and attack them with visible projectiles.
- Game background redesigned as a procedural starfield/nebula instead of flat black.
- Wave/boss progress moved to a thin horizontal bar at the very top.
- Each wave announces itself once in large text (e.g. `ВОЛНА 1` / `WAVE 1`).
- Pause overlay spacing fixed so buttons no longer overlap the title.
- Save delete button redesigned and deletion now requires confirmation.
- Main menu has slowly drifting enemy bubbles for atmosphere.
- About screen now describes the build as an alpha game for children; developer/contact remain Ponikarov Artem / enhort@gmail.com.
- UI text increased in shops, settings, HUD and overlays.
- UI font atlas refreshed with a slightly condensed/slanted space-console style while retaining RU/EN glyphs.
- Enemy speed icon changed from the duplicated clock icon to a wind/speed icon.
