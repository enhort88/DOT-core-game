# Alpha 0.2 — Big Systems Update

- Ported architecture from Android-only Canvas to Java + libGDX with shared `core`, `android`, and `lwjgl3` modules.
- Added desktop launch path.
- Added full main menu, five save slots, settings, RU/EN, About and Exit.
- Added shop branches: General / Finger / Turrets / Drones / Elements.
- Added passive income and risk-for-income upgrades.
- Added waves, bosses, planet integrity, overrun and defeat.
- Added turret shields, paid repairs, auto-repair, weapon unlocks, 5→7 slot progression.
- Added 7→9 drone slot progression, gun/missile/kamikaze/support drone types, respawn and support healing.
- Added drone elemental auras.
- Added Fire / Ice / Lightning shared status system.
- Added Gravity-exclusive finger mechanics with black holes and spatial rifts.
- Added usage-based skill XP alongside purchased upgrades.
- Added synthesized SFX and vibration feedback.
