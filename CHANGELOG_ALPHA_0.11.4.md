# DOT//CORE Alpha 0.11.4 — Flow & Drone AI

- Android/system Back is now caught by libGDX and navigates back through overlays instead of closing the game.
- In gameplay: Effect Shop -> Effect Setup -> battle; Debuffs/Shop -> battle; Back from battle opens pause.
- Main menu Back no longer exits accidentally; explicit Exit remains.
- Added left/right swipe navigation between Finger / Turrets / Drones shop tabs.
- Shop swipe has a small page-slide transition.
- Support drones globally detect damaged allied drones and fly to them from anywhere on the battlefield.
- During boss fights, all combat drones globally acquire the boss as priority target immediately.
- Reworked in-game Store, Debuffs, Effect Store and Effect Setup visual language into a single seamless glass-console layout:
  flatter segmented navigation, softer cards, shared headers/footers, less floating-button look.
- Version bump to 0.11.4-alpha.
