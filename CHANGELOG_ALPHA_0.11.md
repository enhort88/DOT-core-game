# DOT//CORE Alpha 0.11 // ASCENSION

## Major systems
- Added first-run commander-name flow and replayable story briefing.
- Added progressive hidden technology discovery instead of exposing the full tree.
- Cheat mode now bypasses technology gates and exposes the full game for testing.
- Added 3-second Annihilation usage limit + cooldown HUD.
- Added Repair XP / Repair Skill and multi-tap turret repair.
- Added staged geometric enemy silhouettes by wave.
- Added hostile Corrosion, Parasite and Disruption mechanics.
- Added temporary enemy touch shields that reject direct finger taps.
- Added infected turret/drone friendly-fire behavior and tap cleansing.
- Added stronger element-specific visual language for Fire, Ice and Lightning.
- Added sequential Effect Shop discovery after boss milestones.

## Balance
- Kept Wave 1 as a one-tap introductory wave.
- Slightly slowed default turret fire rates again so Fire Rate upgrades are meaningful.
- Enemy movement keeps scaling by waves/bosses and player-selected Debuffs.
- Repair cost/work scales with wave and turret shield level.

## UX
- Player name appears in main menu and save slots.
- Settings can replay the introduction/change commander name.
- Effect Shop remains hidden until boss 5 in normal mode.
- Annihilation charge/cooldown is visible below Planet HP.
