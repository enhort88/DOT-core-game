# Alpha 0.11.8 — Boss Pressure / Element Economy

- Boss countdown is now a huge translucent number in the background of the battlefield.
  It is rendered behind enemies/turrets/drones so it reminds the player about the timer without blocking combat.
  The old tiny top-right boss timer was removed.
- Added a top combat safe zone. Regular enemies now enter fully below the wave/boss progress line and cannot be pulled back into the HUD lane by gravity.
- Rebalanced elemental technology unlock prices:
  - Fire: 12,000 C
  - Ice: 30,000 C
  - Lightning: 75,000 C
- Element unlock conditions remain progressive (5 / 7 / 9 defeated bosses) and cheat mode still unlocks everything for testing.
